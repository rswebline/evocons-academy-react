# Evocons Academy — Sprint 1

Prima bozza React/Vite autonoma della homepage `academy.evocons.it`, limitata a navigazione e Hero.

## Avvio

```bash
npm install
npm run dev
```

Aprire l'URL localhost indicato da Vite.

## Build

```bash
npm run build
```

La cartella `dist/` è destinata al virtual host Nginx di `academy.evocons.it` (DNS, HTTPS e deploy ancora da configurare).

## Stato e limitazioni

- Bozza autonoma, **non ancora integrata con i componenti del repository corporate**: la connessione GitHub non era disponibile durante la preparazione.
- Fotografia temporanea caricata da Unsplash, da sostituire con un asset locale autorizzato prima della pubblicazione.
- Il marchio nell'header è un segnaposto testuale/grafico: sostituire con il logo ufficiale.
- Le voci del menu e le CTA puntano a sezioni ancora da realizzare: nella R1 finale andranno collegate a contenuti reali o gestite come link disabilitati.
- Le pagine corsi, i moduli, i prezzi, le FAQ e i contenuti successivi non fanno parte dello Sprint 1.
